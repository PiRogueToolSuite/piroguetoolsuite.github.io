---
title: "Show certificate warning details"
---

The first time we browse the dashboard served with a self-signed certificate,
the browser warns us about the situation.

Accessing details of the self-signed certificate differs depending on the browser we use:

{{< tabs "show-detail-browser" >}}
{{< tab "Firefox" >}}
1. Verify the address
2. Click on `Advanced`

{{< figure src="img/self-signed-warning-firefox-1.png" alt="Firefox show security warning details" caption="Firefox show security warning details" class="d-block mx-auto shadow" >}}
{{< /tab >}}
{{< tab "Chrome" >}}
1. Verify the address
2. Click on `Advanced`

{{< figure src="img/self-signed-warning-chrome-1.png" alt="Chrome show security warning details" caption="Chrome show security warning details" class="d-block mx-auto shadow" >}}
{{< /tab >}}
{{< tab "Safari" >}}
1. Verify the address
2. Click on `Show details`

{{< figure src="img/self-signed-warning-safari-1.png" alt="Safari show security warning details" caption="Safari show security warning details" class="d-block mx-auto shadow" >}}
{{< /tab >}}
{{< /tabs >}}
